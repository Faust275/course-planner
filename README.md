# 课表 Course Planner

一个面向学生的单文件网页应用（PWA）：课表、日程、四象限待办、日历、专注计时、记账、成绩、抽卡收集、每日一句等。

**交付形态是一个 `index.html`**：CSS、JS、诗词/词库语料全部内联，双击即可使用，也可直接转发。开发期源码拆成多文件，构建时打包回单文件。

## 快速使用

- **直接用**：双击 `index.html`，或把它发到任意设备用浏览器打开。
- **托管**：放到任意静态服务器根目录即可；此时可额外放 `sw.js` 启用离线缓存，
  以及 `manifest.webmanifest` + `icon-192.png` / `icon-512.png` 启用「安装到桌面」与长按快捷方式。

数据保存在**各自设备的浏览器**里（优先 IndexedDB，`file://` 或隐私模式自动回退 `localStorage`），不随文件复制。跨设备迁移用应用内的「同步码」。

## 构建

```bash
cd course-planner-web
python3 build.py          # 生成 index.html
```

各模块均为全局 IIFE、无 `import`，因此按模板里的 `<script>` 顺序直接内联即可，**不需要打包器**。

若手上只有旧的单文件、想回到模块化源码：

```bash
python3 sync_from_index.py   # 需要先把 SRC 指向目标 html
python3 build.py
```

## 深链接（装到桌面后一键直达）

每个模块都有自己的 hash 地址，打开就是那一页：

| 地址 | 落到哪里 |
|---|---|
| `#/today` | 今日 |
| `#/tasks` | 待办（任务分页） |
| `#/tasks/diary`、`#/diary` | 待办 → 日记分页（后者是给快捷方式用的别名） |
| `#/notes`、`#/inspiration` | 待办 → 灵感分页 |
| `#/settings/basic` | 设置 → 基础设置（分类页） |
| `#/settings/desktop` | 设置 → 首页与模块 → 桌面与快捷 |

页面内切换模块时地址栏会跟着更新，所以直接复制地址栏就是可用的链接。
`manifest.webmanifest` 里的 `shortcuts` 用的就是这几个地址，装到 Android / 桌面 Chrome 后
长按图标会出现「今日课表 / 写日记 / 待办」。

- manifest 与图标是**可选伴侣文件**（和 `sw.js` 一样）：单文件转发时它们不在场，
  代码会先探测再挂 `<link rel="manifest">`，不会在控制台留下 404。
- 图标默认是靛蓝日历（`make_icons.py` 生成）。想换成自己的图：
  `python3 make_logos_icon.py 你的头像.png` → 覆盖 `icon-192.png` / `icon-512.png` /
  `icon-512-maskable.png` / `apple-touch-icon.png`。这几个文件已加进 `.git/info/exclude`，
  本机生效但不会进仓库（角色立绘版权归原著作权人）。
- 已安装的 PWA **不会自动换图标**：需要先卸载，再重新「添加到主屏幕」。
- `file://` 打开时不会注册 SW、也不挂 manifest，但**深链接照常生效**（自己拼一个带 `#/today` 的路径即可）。

## 目标（计划页的第二个分页）

「目标」回答的是「这些事加起来有没有把我送到想去的地方」，所以它不重复计划与待办，只做中间那层判断：

```
目标（这学期把高数补上来）
  ├─ 关键结果 1：每周自习 5 天        → 挂一条计划（自动算）
  ├─ 关键结果 2：作业按时率 ≥90%      → 挂一组待办（自动算）
  └─ 关键结果 3：期中 ≥80            → 自己填一个数（手动）
```

| 问题 | 处理方式 |
|---|---|
| 进度怎么算 | 每条 KR 各算各的，总进度 **等权平均**，不做权重 |
| 没有数据的 KR | 不进分母（绑的计划删了 / 周期内没待办 / 期中还没考） |
| 挂计划的范围 | 只统计 **目标周期内** 的打卡，到期后自然冻结 |
| 挂待办的范围 | 周期内有截止日期的 **顶层** 待办，按标签（任一命中）、课程圈定 |
| 同时在办 | **最多 5 个**，写死不提供设置 |
| 到期没达成 | **不删、不扣分**，挪到「已归档」，进度按周期冻结 |
| 周期选项 | 只有「本学期」和「自定义起止」，不做日/周目标（与计划重叠） |
| 月末复盘 | 每月最后三天在目标页提示一次，一键把进度写进当天日记（只提示，不自动写） |
| 积分 | 达成 100% 并归档 **+60**，每个目标只发一次；周期不满 7 天不发（防止「建个 100% 的目标立刻归档」刷分） |
| 成就 | 「收集 → 成就 → 目标」四枚：第一个目标 / 同时 5 个 / 说到做到 / 月末回头看 |
| 教程 | 新手教程第 10 步专讲目标，会直接切到目标分页；欢迎页与设置页同步讲了装到桌面的快捷入口 |

为什么不给 KR 加权重：个人场景里权重基本靠拍脑袋，拍出来的数比不填更误导。
为什么不自动改目标：一旦有惩罚，人就会开始改目标数字，整页数据就废了。

## 统计、积分与板块联动

- **统计归位待办分页**：待办页新增「象限」「统计」分页；「统计」受 `settings.statsOn` 双隐藏——关掉后待办分页入口与今日「本周已记录」卡片一起消失。
- **积分（养分）来源**：专注（一次 ≥40 分钟固定 10 分）、完成待办、计划打卡 / 完成、目标 KR / 归档、月卡返还。**成就只发徽章、不发任何资源**；睡眠 / 饮食 / 活动已不再发分。统计分页仍有「积分曲线」与「来源构成」，今日卡片显示本周获得与累计总量。
- **双币不互通**：森林模式挣 / 花「森林积分」，抽卡模式挣 / 花「合成玉」；`spendPoints` 只扣积分、`spendJade` 只扣玉，两池不再按 180:1 互相补扣。1 积分 = 180 玉仅用于抽卡定价。
- **专注计分**：一次专注 ≥40 分钟固定给 10 分（≥60 分钟树长 2 记），不足 40 分钟不发；满 60 分钟提醒起来走走；番茄钟默认 45 分钟。
- **板块联动**：
  - 账本 → 统计「消费构成」；时间记录可挂课程 → 统计「课程投入」；
  - 目标 → 今日「在办目标」卡；课程考试 → 日历标记 + 今日「本周考试」；
  - 目标新增「学期 GPA」KR（按已出分课程加权 GPA，未出分显示「待出分」）；
  - 专注累计里程解锁成就并发放积分（10 / 30 / 60 / 100 / 200 小时）。
- **健康提示**：今日按用户自定阈值（睡眠下限 / 热量超标 / 活动下限）给轻提示，可总开关；默认睡眠 6h、热量跟随每日目标、活动 0=关闭。
- **设置三级结构**：首页只放 6 张分类卡（基础设置 / 首页与模块 / 记录与统计 / 奖励与目标 / 识别与数据 / 帮助），点进去是该类的 4~5 个条目，再点进具体页；返回逐级回退。地址同步为 `#/settings/basic`（分类）与 `#/settings/desktop`（具体页），深链直接打开时会自动补上所属分类。
- **统计显示开关**：时间统计 / 积分曲线 / 积分来源 / 消费构成 / 课程投入，可勾选。
- **合成玉换算**：1 积分 = 180 合成玉，600 玉一抽（≈ 3.33 积分）。图标是矢量重绘的金色多面体，跟尺寸缩放不糊。
- **商店（收集 → 商店）**：
  - 月卡按当前模式计价：森林 300 积分 / 抽卡 54000 玉（抽卡数值为占位，待定）；同一时间只能持有一个模式的月卡，返还也进该模式的币种；
  - 满潜重复：抽到第 7 份及以后存入 `shop.dupPool`，在商店一键按 1 积分 = 180 玉固定换成合成玉（两币不互通，满潜是抽卡子系统产物）。
- **种树（专注即种树）**：4 个树位；一次 ≥40 分钟专注会在空位种下当前树种或养护现有树，中途中断则本次种子枯萎。五个阶段（1→2、2→3 各 1 记，3→4 需 2 记，4→5 需 3~6 记，越珍稀越多）；枯萎可花 5 养分复活（阶段保留、进度归零）；长成后可「收获入收藏」腾出树位。树种图鉴按累计专注时长解锁珍稀现实树种（珙桐 / 水杉 / 红豆杉 / 鹅掌楸 / 华盖木 / 龙血树 / 普陀鹅耳枥 / 百山祖冷杉），解锁后才显示资料卡。养分用于浇水（2）与复活（5）。
- **桌面侧边栏折叠**：顶栏左侧按钮，侧栏 236 → 68px 只留图标，状态存 `settings.ui.sidebarMini`，刷新保持；≤900px 不出现（窄屏本来就没有侧边栏）。
- **机制主题皮肤（浅色 + 深色）**：设置 → 外观里有「机制主题皮肤」开关（默认开）与「明暗模式」（跟随系统 / 浅色 / 深色）。开启皮肤后自动跟随奖励机制——森林=自然生机（绿调、大圆角、藤蔓/花叶），抽卡=工厂硬核（黑框硬阴影、HUD 四角、蓝图网点、部署箭头）。深色下：森林=夜晚林间（墨绿底 + 萤火虫），抽卡=基建终端（黑砖 + 荧光绿 + 网格 + 扫描线）；深色时主色派生色会自动向深色表面混合，避免亮色块。机制只定「结构」，主色仍可由上方色块覆盖（手动选色后自动关闭跟随）；状态存 `settings.themeSkin` / `themeSkinAuto` / `themeMode`，根节点挂 `data-mech` + `data-mode`。新抽卡体系（多卡池）留待后续。

## 待办 ↔ 时间投入 与 月历时间块

**待办 ↔ 时间投入（双向）**

- 番茄钟关联待办时，结束会自动写一条活动记录（带 `taskId`），这段专注就记在待办头上；
  象限里手动记活动时也可以在下拉里选一条未完成待办挂上去。
- 待办行和编辑弹窗里显示「已投入 X」，弹窗里还能看到最近 5 条记录，点一条跳到象限页那天。
- 分钟数**只从活动记录里算**，不再从番茄 sessions 加一遍——同一段专注两边都有，重复算就是假数据。

**月历时间块（事后补录）**

「日历」页选中某天后，下方是一条 48 格的时间带（半小时一格）：

- 点格子 → 选类型（学习 / 运动 / 社交 / 休息放松 / 其它）和时长（半小时到 4 小时），
  连续同类的格子自动合并成一条活动记录，直接进象限和统计。
- 睡眠、用餐、课程画出来但**不可改**；象限里手动记的活动同样只读——
  补录只动自己写的那层（`from: 'block'`），不会冲掉认真填过的名字和备注。

**统计「今年」档**

统计与复盘的五档之外新增「今年」：1 月 1 日 → 今天，参照区间是去年同期（去年 1/1 → 去年的今天）。
跨度半年以上时热力条自动从「按周」换成「按月」，一格一个月。

## 横滑手势与 PWA 更新提示

**横滑**：课表页左右滑切周、日历页左右滑切月（与页内箭头同向：左滑=下一个）。
`UI.addSwipe` 三道防误触——起点在横向可滚动的子元素里不抢手势、水平位移 ≥60px
且明显大于纵向位移才触发、全部 passive 监听不影响滚动。

**PWA 更新**：`sw.js` 对页面导航请求走 **network-first**（断网才回退缓存），
修复了旧 cache-first 策略下「sw.js 不变就永远拿不到新版 index.html」的坑；
新 SW 被安装接管时页面右下角弹「应用已更新 · 立即刷新」Toast，点击即换新版。
注意：SW 注册要求 `load` 事件，而 boot 在其后才跑完——app.js 里用 `onReady`
兼容了「load 已触发」的情况，改这块时别把注册时机改回去。

## 单次调课 / 停课 / 调休（高校刚需）

大学里的「国庆把周二课调到周六」「第 8 周停课一次」「实验课临时换去三教 402」，用**单次例外**解决，不动整学期周历：

- 入口在两处：今日页课程卡的「调整」按钮、课程详情弹窗的「单次调整」——都可以管理某一天的 停课 / 换教室 / 调课到其它日期（可选节次），已有调整可撤销；同课同天重复设置自动覆盖。
- 判定逻辑在 `assets/js/course-exception.js`（**纯模块，不依赖 Store**，在 store.js 之前加载）。
  「今天的实际课表」一律走 `Store.coursesOnDate(dateStr)`，今日、日程、月历、统计、页面内提醒全部由此出数；
  被停的课在今日页灰显划线（标注「本次停课 / 已调走」），调进来的课标「调自 X/X」。
- 导出 `.ics` 时用标准 **EXDATE** 排掉原日期，换教室/调课在对应日期生成单独事件——手机日历和 App 口径一致。

## 待办抽屉与计划专注块（Time-Blocking）

「我想在今天下午专门做待办 A」的闭环：

- 月历选中日的**待办抽屉**列出近期未完成待办，点一条就在当天时间轴自动划 1 小时「计划 · 学习」块（从当前时间或 8:00 起找第一个空档，自动带上待办关联）。
- 时间块编辑弹窗可选手「关联待办」与性质（**实际投入 / 仅作计划**）。
- 计划块在时间带上是**虚线格**——「打算学」和「已经学了」一眼可分；计划块**不进统计、不进已投入**，不是假数据。
- 待办编辑弹窗显示「今日计划 X · 今日实际 Y（还差 Z）」，计划 vs 实际的复盘就在待办头上。
- 点格子把计划块改成实际（或清除重涂）即完成闭环；「清空这天的时间块」连计划一起清。

## 近期新增（README 此前遗漏）

以下功能是后续迭代加入、已随当前版本上线，但早期 README 未记录，集中补在此处，避免接手人遗漏或重复实现。

### 一键自然语言生成待办（`assets/js/task-nlp.js` → `TaskNLP.parse`）

待办输入框在**新建态**失焦 / 回车时自动解析中文自然语言，提取并清洗出规范任务：

- 优先级：`!重要` / `!高` / `!!` / `★` / `【重要】`；低优 `!低`
- 标签：`#作业`
- 课程绑定：`@高数`，并支持别名模糊匹配（高数→高等数学、大物→大学物理、线代→线性代数……）
- 时间：「下午3点半」「晚上8点」「15:30」「9点20」，以及模糊时段（今晚 / 下午 / 中午 / 早上）
- 日期：相对（今天 / 明天 / 后天 / 大后天 / N天后）、星期（下周三 / 本周六 / 周五，已过则顺延）、绝对（`2026-10-25` / `10月25日` / `10/25`）

解析结果（标题 / 日期 / 时间 / 优先级 / 标签 / 课程）直接回填待办表单；**编辑已有任务时不触发**（`tasks.js` 仅在 `!isEdit` 时调用）。

### 白噪音（`assets/js/white-noise.js` → `WhiteNoise`）

专注页内置、原生 Web Audio 合成的音效，**零外部资源、完全离线**：雨声 / 粉红噪音 / 深沉褐噪 / 全频白噪四种音色，5 秒无缝循环缓冲（首尾交叉淡入淡出消除爆音），含平滑淡入淡出与音量渐变，由 `pomodoro.js` 调用。

### 学业生活白皮书（`assets/js/white-paper.js` → `WhitePaper`）

统计页的「白皮书」入口：聚合本学期 GPA、课程投入排行、作息规律度、深度专注工时、消费收支、心情晴雨表、目标达成，以杂志排版弹窗呈现，并可一键用 Canvas 2D 导出 750×1080 高清 PNG 海报。由 `stats.js` 调起 `WhitePaper.openDialog()`。

### 全局搜索（`assets/js/search.js` → `Search`）

顶栏搜索按钮，或快捷键 **Ctrl / ⌘ + K** 唤起；结果按模块分组、关键词高亮、点击跳转定位。快捷键在 `app.js` 绑定。

### 导航自定义（设置 → 首页与模块）

可对模块**排序**与**隐藏**（`settings.nav` + `navOrder`）；底部 tab 最多展示 5 项，超出部分收进「更多」弹窗。桌面端侧边栏可折叠为 68px 只留图标（`settings.ui.sidebarMini`），≤900px 自动隐藏。

### 新签到机制：有效动作 / 全勤 / 摸鱼券

抽卡经济的留存体系改为「**完成有效动作**」签到（`Store.markAction`），取代旧版「打开过模块」口径：

- **有效动作**：完成课程相关、待办相关等动作，重度 2 分 / 轻度 1 分，累计成长值满 10 换 1 张摸鱼券
- **全勤**：滚动连续 7 天（周全勤）/ 30 天（月全勤）发奖，人人可得

- 月卡仅额外多一份积分返还，不再垄断奖励

数值与判定见 `ROADMAP.md` 抽卡经济章节与 `store.js` 的 `markAction` / `settleStreak` / `grantTicket`。

## 工程约定

- **CSS 类名统一 `cp-` 前缀**，避免全局冲突。`pet-` 用于桌宠，打印文档（成绩单窗口）自带独立样式，不加前缀。
- 新增页面放 `assets/js/views/`，通用能力放 `assets/js/`，并在 `src/index.template.html` 里按依赖顺序引用。
- `el()` 的 `class` 会**按空格逐个 token** 补前缀：`'heat lv-3'` 会变成 `cp-heat cp-lv-3`，
  已经带 `cp-` 的原样保留。所以 **CSS 里必须写 `cp-` 前缀**，哪怕 JS 侧写的是裸名字。
  这条坑很隐蔽：类名对不上不报错，只是样式静默不生效（热力格曾整片透明、月历的今日框不亮）。
- 直接给 `node.className =` 或 `classList.add()` 不经过 `el()`，**不会补前缀**；
  少量历史代码（桌宠、诗词弹窗）依赖这个行为，写新代码时不要跟着学。
- 改完源码务必跑一次 `build.py`，并确认 `index.html` 同步更新。
